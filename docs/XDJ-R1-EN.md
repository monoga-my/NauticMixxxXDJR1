# Pioneer XDJ-R1 in NauticMixxx

Files:
- `controllers/Pioneer_XDJ_R1_RX3/`. The XML is generated by
  `scripts/generate-xdj-r1-preset.py`; edit that script, not the XML.
- Sound Color FX chains `effects/chains/RX3 PITCH.xml` and `RX3 CRUSH.xml`.
- Patch `0046` adds the MATCH filter and the fixed Beat FX numbers the mapping
  uses. Beat FX needs a build with that patch.
- `effects/chains/XDJ-R1 TRANS.xml`, `XDJ-R1 FLANGER.xml` and `XDJ-R1 ECHO.xml`
  are no longer used by the mapping (Beat FX moved to the native unit 1).

The preset also uses the shared `Nautic-RX3-Browser.js` and
`Nautic-RX3-Encoder-Pioneer-Roland.js` from `controllers/Pioneer_Roland_RX3/`.
The installers copy those into the same folder as the preset.

The preset is based on Helton Lidio's community "Pioneer XDJ-R1" Mixxx mapping.
Its MIDI addresses were checked against the List of MIDI Messages in the XDJ-R1
operating instructions. The manual prints note and CC numbers in decimal. The
XML uses hexadecimal.

## Controls

| Section | Control | Result |
| --- | --- | --- |
| Deck | PLAY/PAUSE | Acts on press. Pressed while CUE is held, the deck keeps playing when you let go of CUE |
| Deck | CUE | CDJ style: while playing, back to the cue point and pause; while paused elsewhere, set the cue point there; while paused on it, play for as long as you hold it. With no cue point, it sets one |
| Deck | SHIFT + MASTER TEMPO | Quantize on/off for both decks. The MASTER TEMPO light keeps showing MASTER TEMPO |
| Deck | TEMPO slider | 14-bit. The **−** end always slows the track, whatever the *Pitch/Rate slider direction* preference says |
| Deck | TEMPO RANGE | 6% → 10% → 16% → WIDE (±100%), lit. SHIFT + TEMPO RANGE steps to the next range |
| Deck | SYNC | Stays on until pressed again, and is lit while on. Aligns the beat when switched on |
| Deck | MASTER | Makes this deck the sync leader, and is lit while it is |
| Deck | VINYL | **On** (lit): touch the top of the platter to scratch or backspin; turn the side to nudge the tempo. **Off**: CDJ mode, where the whole platter nudges the tempo |
| Deck | AUTO BEAT LOOP press | Starts a loop of the deck's loop size (4 beats at first, then the last size used). Press again to leave the loop. SHIFT + press re-enters the last loop |
| Deck | AUTO BEAT LOOP turn | Right doubles, left halves the loop (and the next loop's size). SHIFT + turn jumps by the beat-jump size |
| Deck | HOT CUE A, B, C, CALL | Hot cues 1–4: set a cue, or jump to it. Lit when the cue is set. SHIFT + button deletes the cue |
| Deck | MODE | Switches A/B/C/CALL to the **KEY** layer, where MODE goes dark: A = key up, B = key down, C = match key to the other deck, CALL = back to the original key. Press MODE again for hot cues |
| Beat FX | TRANS / FLANGER / ECHO | Runs that effect (TREMOLO, FLANGER, ECHO) on NauticMixxx's own Beat FX and opens its BEAT FX panel on screen; press again to turn it off. One effect runs at a time: pressing the same effect on the other deck adds that deck, a different effect moves to that deck alone |
| Beat FX | ROLL | Loop roll on that deck at the BEAT size; press again to stop |
| Beat FX | BEAT | Beat time: moves the panel's X-PAD across the effect's beat values (1/16 up to 4 beats or more) |
| Beat FX | LEVEL/DEPTH | The Beat FX dry/wet, shown as LEVEL/DEPTH in the panel |
| Mixer | SOUND COLOR FX + COLOR | FILTER, PITCH, CRUSH, NOISE on both decks; COLOR sets the amount (table below) |
| Mixer | Channel level meters | Show the deck level on the unit |

How each Sound Color FX responds to COLOR:

| Button | QuickEffect preset | COLOR behavior |
| --- | --- | --- |
| FILTER | RX3 FILTER (4) | Left of centre = low-pass, right = high-pass |
| PITCH | RX3 PITCH (5) | Left = pitch down, right = pitch up |
| CRUSH | RX3 CRUSH (6) | Amount grows as you turn away from centre, in either direction |
| NOISE | RX3 NOISE (3) | Amount grows as you turn away from centre, in either direction |

The mapping loads effects **by their position in Mixxx's preset lists**. The
installers and `scripts/install-xdj-r1-windows.ps1` set two lists:
- **Quick Effect list:** REVERB, PING PONG, NOISE, FILTER, PITCH, CRUSH.
- **Effect chain list:** XDJ-R1 TRANS, FLANGER, ECHO, at the top.

If you reorder either list in **Preferences > Effects**, the buttons load the
wrong effects. Run the install script again to put them back.

## Browser controls

| Gesture | Result |
| --- | --- |
| Turn SELECT in PERFORMANCE | Zoom both waveforms: right = in, left = out |
| Turn SELECT in BROWSE, INFO, SHORTCUT or grid editing | Move through the list, as before |
| Press SELECT on the track list | Load the highlighted track into **that** deck |
| Press SELECT anywhere else | Open BROWSE, or enter the highlighted source/folder |
| SHIFT + press SELECT | Always open/enter, never load |
| BACK | Go back one level |
| SHIFT + BACK | VIEW: switch between PERFORMANCE and BROWSE |
| TIME in BROWSE | MATCH: show only the tracks of the list on screen that mix with the master deck (compatible key, tempo within 16% of its current BPM). The title line shows the key, BPM and count. Press again for the whole list |
| SHIFT + TIME | SOURCE |

The track list shows a **KEY** column. Its text is larger than in 2.0.0 and no
longer uses the condensed Arial Narrow font.

## Windows 11 (including handheld PCs such as the ROG Xbox Ally X)

1. Install Pioneer's **XDJ-R1 driver** for Windows. You need it for both audio
   and MIDI.
2. Connect the XDJ-R1 by USB. On a handheld with only USB-C ports, use a USB-C
   to USB-B cable or a powered hub. Switch both decks of the unit to MIDI
   (DJ software) control, as described in "Using the DJ software" in its
   manual.
3. Install a build that includes this preset. The quickest way is your fork's
   **NauticMixxx Windows x64** GitHub Actions workflow. You can also build
   locally with [BUILDING.md](BUILDING.md). This build auto-selects the preset
   when the MIDI port name contains `XDJ-R1`.

   With the official 2.0.0 app, run the drop-in installer from this repository
   folder instead:
   `powershell -NoProfile -ExecutionPolicy Bypass -File scripts\install-xdj-r1-windows.ps1`.
   It installs the mapping, effects and font change. The KEY column and larger
   track text still need the new build.
4. In NauticMixxx, open **Preferences > Sound Hardware**. Use **WASAPI** with
   the XDJ-R1: on the Ally, choosing ASIO crashed the app. Set Main to the
   XDJ-R1 master output and Headphones to its cue output. A 256–512 sample
   buffer is a safe start on a handheld.
5. If the preset was not selected automatically, open
   **Preferences > Controllers**, select the XDJ-R1, choose
   **Pioneer XDJ-R1 (NauticMixxx RX3)** and tick **Enabled**.

**Tip:** for the biggest picture, use full screen (**View > Full Screen**, or
F11). The skin scales with the window, so dropping the title and menu bars
makes everything larger.

## Not yet confirmed on hardware

These were checked only in software, by `node scripts/test-xdj-r1-preset.js`:

* Lights the manual lists only as inputs: Sound Color FX, Beat FX, TEMPO RANGE,
  VINYL, MODE and MASTER.
* Whether the BEAT control sends absolute values (0–127), which is what the
  manual suggests and how the mapping treats it.
* Whether TIME sends note 0x3E as the manual says (MATCH).
* Whether TEMPO RANGE sends a separate note for each range, or the same note on
  every press. The script handles both cases.
* Whether the unit shows the loop length sent on notes 0x6E–0x78.

If a control misbehaves, set `PioneerXDJR1.debug = true` at the top of
`Pioneer-XDJ-R1-RX3-scripts.js`. Then start NauticMixxx with
`--controller-debug` and note what it logs.
